# Jog On (iOS)

Milestone 1 of the build spec: tab bar, theme and all 14 screens with dummy data.

## Run it
1. On a Mac: `brew install xcodegen && cd JogOn && xcodegen` then open `JogOn.xcodeproj`.
2. Add the Archivo font files (see spec) to `JogOn/Theme/Fonts` and list them under UIAppFonts. Until then the app falls back to the system font.
3. Run on an iOS 18 simulator.
